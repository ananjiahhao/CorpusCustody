# Obligation guide

The obligation matrix answers one question per license class: what does using
this material oblige you to keep or disclose?

| Class | Notice | Share-alike | Source disclosure |
|---|---|---|---|
| permissive | yes | no | no |
| conditional | yes | partial | no |
| share-alike | yes | yes | yes |
| unknown | treat as all | treat as yes | treat as yes |

The unknown row is deliberately strict. An unknown license is not a free
license; the gate blocks until a human classifies it.
